# Web Clock

純前端（HTML / CSS / JavaScript）的網頁時鐘，無需任何建置工具。

## 功能

- **顯示型態**：數字鐘 或 指針式（SVG，秒針平滑走動）
- **背景色**：
  - 深灰
  - 淺灰
  - 自選底色（色彩選擇器）
  - 動態色彩（色相隨時間循環，可調整變化速度）
- **自動對比**：指針／數字顏色會依背景的相對亮度（WCAG contrast ratio），自動切換為深灰或淺灰
- 顯示秒數、12 / 24 小時制切換
- 設定會記憶於瀏覽器 `localStorage`

## 使用方式

直接用瀏覽器開啟 `index.html`，或啟動本機伺服器：

```bash
python3 -m http.server 8000
# 開啟 http://localhost:8000
```

點擊右上角 ⚙ 開啟設定面板，按 `Esc` 或點擊面板外即可關閉。

## 檔案結構

| 檔案 | 說明 |
| --- | --- |
| `index.html` | 頁面結構與設定面板 |
| `style.css` | 版面與樣式（以 CSS 變數 `--bg` / `--fg` 控制顏色） |
| `clock.js` | 時鐘繪製、背景色與對比色計算、設定儲存 |
